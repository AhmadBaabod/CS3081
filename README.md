# CS3081 Artificial Intelligence

Coursework for **CS3081 Artificial Intelligence** at Effat University (Spring 2026, Dr. Naila Marir), in Python.

| Folder | What it covers |
|---|---|
| [`tic-tac-toe-minimax/`](tic-tac-toe-minimax/) | An unbeatable Tic-Tac-Toe AI using the **Minimax** algorithm, with a pygame interface |
| [`assignment-2-search-and-logic/`](assignment-2-search-and-logic/) | Assignment 2: **Breadth-First Search** route finding across Saudi cities, and a **propositional-logic knowledge base** |
| [`lab3-search-and-knowledge/`](lab3-search-and-knowledge/) | Lab 3: BFS pathfinding and **knowledge-base reasoning** with logical inference, plus the lab report |

Each folder has its own README with details and run instructions.

## Topics

- Adversarial search (Minimax, optimal play)
- Uninformed search (Breadth-First Search) on a graph of cities
- Knowledge representation and propositional logic inference

## Run

```bash
# Tic-Tac-Toe
cd tic-tac-toe-minimax
pip install -r requirements.txt
python runner.py

# Search and logic
cd assignment-2-search-and-logic
python assign2_part1_search.py
python assign2_part2_knowledge.py
```
